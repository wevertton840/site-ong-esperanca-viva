# Instituto Esperança Viva - Website Institucional

Aplicação web estruturada com foco em acessibilidade digital, arquitetura modular e práticas profissionais de engenharia de software.

## Funcionalidades
- Arquitetura modular em JavaScript (`storage.js`, `validation.js`, `views.js`).
- Formulário com validações de dados e armazenamento local no navegador.
- Total conformidade com as diretrizes de acessibilidade **WCAG 2.1 (Nível AA)**.

## Estrutura de Ramificação (GitFlow)
- `main`: Código final de produção estável.
- `develop`: Ramificação de integração contínua de novas alterações.
- `feature/*`: Desenvolvimento isolado de funcionalidades.
- `docs/*`: Documentação e especificações do sistema.

## Execução Local
1. Clone o repositório.
2. Abra o ficheiro `index.html` em qualquer navegador web ou através da extensão Live Server no VS Code.
